# Мыльный калькулятор (PWA)

Порт калькулятора [soapcalc.net/calculator](https://soapcalc.net/calculator) — прогрессивное
веб-приложение без зависимостей: работает офлайн, устанавливается на телефон, серверной части нет.

## Как запустить

**Опубликовано:** https://elbub1979.github.io/soap-calc/ (GitHub Pages из ветки `main`).
Любой `git push` в `main` обновляет сайт через ~1 минуту; не забудьте поднять версию
кэша в `sw.js`, чтобы установленные копии подхватили обновление.

**На телефоне / как приложение.** Выложите папку на любой статический хостинг
(GitHub Pages, Netlify, Cloudflare Pages, обычный nginx — нужен только https). Откройте
адрес на телефоне и выберите «Добавить на главный экран» (Android: меню Chrome → «Установить
приложение»; iOS: «Поделиться» → «На экран Домой»). После первого открытия приложение
работает без интернета — service worker (`sw.js`) кэширует все файлы.

**Одним файлом, без хостинга.** `npm run build` собирает `dist/soap-calc.html` — всё
встроено внутрь, файл открывается с диска двойным кликом и его можно переслать на телефон
(мессенджером, почтой) и открыть в браузере. Офлайн-кэш и установка на главный экран в этом
варианте не нужны: файл и так лежит локально.

**Локально при разработке.** `npm start` поднимает `python3 -m http.server` на
http://localhost:8080. Сервер нужен только потому, что браузеры не загружают ES-модули
(`import`) по `file://`; никакой логики на нём нет.

```sh
npm start      # http://localhost:8080
npm test       # node --test
npm run build  # dist/soap-calc.html — автономный файл
```

При изменении файлов поднимите версию кэша `CACHE` в `sw.js`, иначе установленное
приложение продолжит показывать старую версию до следующего обновления service worker.

## Структура

- `src/oils.js` — база из 149 масел (извлечена из бандла soapcalc.net). `sap` — KOH SAP.
- `src/calc.js` — расчётное ядро без DOM (щёлочь, вода, отдушка, свойства, Sat:Unsat).
- `src/app.js`, `src/styles.css`, `index.html` — интерфейс.
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA: установка на главный экран и офлайн-кэш.
- `build.mjs` — сборка автономного `dist/soap-calc.html`.
- `test/calc.test.js` — тесты с ручными расчётами.

## Формулы

| Величина | Формула |
|---|---|
| SAP рецепта (KOH) | Σ (%ᵢ / 100 · sapᵢ) |
| Щёлочь KOH | SAP · вес масел · (1 − пережир/100); при 90% KOH ещё ÷ 0.9 |
| Щёлочь NaOH | то же · 40 / 56.1 (≈ 0.713) |
| Вода, % от масел | вес масел · % / 100 |
| Концентрация щёлочи c | щёлочь · (1 − c) / c |
| Вода : щёлочь a:b | щёлочь · a / b |
| Отдушка | oz/lb · lb масел, или г/кг · кг масел (1 oz/lb = 62.5 г/кг) |
| Твёрдость | лауриновая + миристиновая + пальмитиновая + стеариновая |
| Очищение | лауриновая + миристиновая |
| Пышная пена | лауриновая + миристиновая + рицинолевая |
| Кремовая пена | пальмитиновая + стеариновая + рицинолевая |
| Уход | олеиновая + линолевая + линоленовая + рицинолевая |
| Йод, INS | средневзвешенные значения масел |

Свойства рецепта — средневзвешенные по процентам, округлены до целых. Для 10 масел
(воски, ряд кислот, Abyssinian и др.) используются ручные значения из SoapCalc.

## Проверка

- Паритет с оригиналом: модули soapcalc.net запущены в Node и сравнены с `calc.js`
  на 20 000 случайных рецептов (все типы щёлочи, режимы воды, единицы, режим % и весов) —
  совпадение 20 000 / 20 000.
- Контрольный рецепт: оливковое 40% / кокосовое 76° 30% / пальмовое 30%, 1000 г, пережир 5%:
  NaOH 144.14 г, вода 380 г (38%), концентрация 27.5%.

### Аудит базы и логики оригинала (данные повторены как есть ради совместимости)

Источники: бандлы calculator / oil-list / print-recipe и тексты страниц helptext, soapqualities,
faq, updates. Список масел (`/oil-list`) использует ту же базу из 149 масел.

**Ошибки в ручных значениях (override), влияют на свойства рецепта:**

| id | Масло | Проблема |
|---|---|---|
| 140 | Salmon Oil | override Iodine 106 / INS 69 (как у Rapeseed), в базе 169 / 16 |
| 142 | Candelilla Wax | override Iodine 106, в базе 32 |
| 145 | Abyssinian Oil | Creamy 80 при пальм.+стеар. = 5; нет Sat/Mono/Poly (эруковая ≈ 55–60% теряется) |
| 31 | Meadowfoam Oil | PolyUnsaturated 100, хотя масло в основном мононенасыщенное (C20:1/C22:1) |
| 149 | Pracaxi Seed Oil | Sat/Mono/Poly 54/42/2 — точная копия Cupuacu (101); Saturated 54 при Hardness 6 |
| 40 | Rapeseed Oil | Creamy 1 при пальм.+стеар. = 5 |

**Пробелы в данных:**

- Нет жирных кислот без override: Mink Oil, Neatsfoot Oil, Lanolin (все 0), Jojoba (12%).
  Такие масла «разбавляют» свойства рецепта нулями.
- INS = 0: Carrot Seed Oil (оценка 1000·SAP − йод = 88), Pine Tar (сознательно: «только для щёлочи»).
- Сумма 8 ЖК > 100%: Loofa Seed (104), Mafura Butter (102), Pumpkin Seed virgin (102).
- INS сильно отличается от оценки «KOH SAP − йод»: Tucuma (175 против 225), Ostrich (128 против 98),
  Canola, Grapeseed, Sheep Tallow, Tamanu (±15–20). По справке INS берётся из книги
  «Essentially Soap», а оценка используется, только если в книге значения нет, так что часть
  расхождений ожидаема.
- Одинаковые данные: Flax = Linseed, Ghee = Milk Fat, Palm Oil = Red Palm Butter.
- SAP чистых кислот близок к теоретическому 56.106/M (лауриновая 0.280 ✓, стеариновая 0.198 ✓,
  пальмитиновая 0.215 против 0.219).
- Правки из журнала обновлений присутствуют (Coconut 92° йод 3, Illipe INS 152 и др.).

**Логика:**

- «Насыщенные» = только лауриновая…стеариновая; каприловая/каприновая (≈ 15% в кокосовом)
  не учитываются, остаток до 100 распределяется пропорционально, поэтому Sat:Unsat у
  кокосового и пальмоядрового немного занижено.
- Норма INS: в калькуляторе 136–165, на странице Soap Qualities — 136–170.
- Справка обещает предупреждение при концентрации щёлочи ≥ 40%, но в новом сайте его нет
  (здесь добавлено).
- В оригинале при вводе весов проценты округляются до 0.01 (остаток идёт самому крупному
  маслу), и щёлочь считается по округлённым процентам. Здесь в режиме «вес» расчёт идёт по
  точным весам (разница меньше 0.01%).
- KOH: для жидкого мыла второй этап воды (разбавление) не рассчитывается, только описан в тексте.
- 40/56.1 вместо точного 39.997/56.106 — разница ~0.01%, на практике несущественна.

## Режим «исправленные данные»

По умолчанию все цифры совпадают с soapcalc.net. Флажок «исправленные данные» (карточка
«Свойства мыла») применяет поправки из `CORRECTIONS` в `src/calc.js`. Поправки меняют
только показатели качества и соотношение Sat:Unsat; **на расчёт щёлочи и воды не влияют**.
Масла с поправкой помечены «✎» в списке и составе; при включённом режиме предупреждение
показывается над таблицей свойств и в печатной версии. Флаг сохраняется в JSON как
`correctedData` (сайт это поле игнорирует).

| id | Масло | Поправка | Основание |
|---|---|---|---|
| 140 | Salmon Oil | йод 106 → 169, INS 69 → 16 | собственная запись базы сайта (Oil List) |
| 142 | Candelilla Wax | йод 106 → 32 | собственная запись базы сайта |
| 40 | Rapeseed Oil | Creamy 1 → 5 | формула сайта (пальм. + стеар.) |
| 145 | Abyssinian Oil | Creamy 80 → 5; Sat/Mono/Poly 0/0/0 → 5/80/15 | формула сайта + литература (эруковая ~55–60%) |
| 149 | Pracaxi Seed Oil | Hardness 6 → 40; Sat/Mono/Poly 54/42/2 → 40/44/4 | противоречие Hardness/Saturated, копия Cupuacu; литература (бегеновая ~20%, лигноцериновая ~14%) |
| 31 | Meadowfoam Oil | Sat/Mono/Poly 0/0/100 → 2/80/18 | литература (в основном мононенасыщенное) |
| 144 | Carrot Seed Oil | INS 0 → 88 | правило сайта: KOH SAP × 1000 − йод |

Уверенность разная: Salmon и Candelilla — два места на одном сайте дают разные цифры;
Rapeseed, Abyssinian, Pracaxi — противоречат формулам сайта; Meadowfoam — только по
литературе. Значения для Abyssinian, Pracaxi и Meadowfoam — оценки.

## Адаптивная вёрстка и выбор фреймворка

Фреймворк не используется — осознанно. React + UI-библиотека добавили бы сборку и 150–300 КБ
кода без выигрыша для одной формы; Tailwind — те же media-запросы, записанные классами, плюс
шаг сборки; Bootstrap/Foundation — 200+ КБ CSS ради сетки, которая здесь занимает 10 строк
на CSS Grid. Всё это мешает автономному файлу и офлайн-режиму. Адаптивность сделана
на чистом CSS, три режима:

- **≥ 1100px** — три колонки (параметры / масла / результат).
- **720–1100px** (планшет) — две колонки, результат на всю ширину снизу.
- **< 720px** (телефон) — один раздел за раз, переключение нижней панелью вкладок;
  краткий итог (щёлочь, вода, масла или текст ошибки) всегда виден в шапке.

Сенсорные экраны (`pointer: coarse`): зоны нажатия ≥ 44px, поля ввода 16px (иначе iOS
увеличивает страницу при фокусе). Учтены `env(safe-area-inset-*)` для «чёлки» и жеста «домой».

## Отличия от оригинала

- Пересчёт на лету (без кнопки «Calculate»), состояние сохраняется в `localStorage`.
- Переключение «% / вес» и смена единиц конвертируют введённые значения.
- JSON импорт/экспорт совместим с форматом soapcalc.net.
- Предупреждение при концентрации щёлочи ≥ 40%, проверка значений воды и веса,
  INCI-состав масел по убыванию доли.
- Интерфейс на русском, светлая/тёмная тема, адаптив, версия для печати.
- Нет импорта legacy-cookie SoapCalc v7.1.
